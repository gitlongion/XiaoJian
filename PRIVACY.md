# 隐私说明 / Privacy

## 中文

小笺不会连接互联网，不包含广告、账号系统、分析工具或遥测功能，也不会收集或上传任何个人信息。

用户的内容库、外观设置和窗口位置只保存在本机：默认是程序旁边的 `data` 文件夹（便携式，拷走即带走全部内容），只有程序所在位置不可写时才改用 `%LOCALAPPDATA%\MyQuoteCard`。软件不写注册表；如果用户选择开机自启动，只会在当前 Windows 用户的“启动”文件夹里放一个启动方式，随时可以自行删除。

背景图片会被复制到上述本地数据文件夹。用户在报告问题时，应自行检查截图和 `content-*.txt`，避免公开私人内容。

## English

XiaoJian does not connect to the internet. It contains no ads, accounts, analytics, or telemetry, and it does not collect or upload personal information.

The content library, appearance settings, and window position are stored only on your machine: by default in a `data` folder beside the program (portable - copy it and your content comes along), falling back to `%LOCALAPPDATA%\MyQuoteCard` only where the program cannot write. The app writes nothing to the registry; if launch-at-startup is enabled, it places a launcher in the current Windows user's Startup folder, which you can delete at any time.

Selected background images are copied to the same local data folder. Before reporting an issue, users should review screenshots and `content-*.txt` to avoid sharing private content.
