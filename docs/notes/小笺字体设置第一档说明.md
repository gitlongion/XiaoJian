# 字体设置第一档：自动字号上限、字号输入、加粗斜体

版本 0.9.4。

起因是一次盘点：「有没有更多的字体设置可以调整」。查代码时发现最值钱的一项不是**加**设置，而是一个**藏起来的硬限制**。

---

## 一、自动字号上限：29 磅是个写死的常数

自动适应只做一件事：**从一个大致的起点往下缩，缩到装得下为止**。它从不往上长。所以那个起点其实就是上限。

```csharp
float start = Math.Min(29.0f, Math.Max(20.0f, Width / 17.0f)) + _card.FontAdjustment;
```

`29.0f` 是硬编码的。后果：

| 卡片 | 自动字号 | 四个字占卡片宽 |
|---|---|---|
| 460×190 | 27.1 磅 | 31% |
| 1000×600 | 29.0 磅 | **15%** |
| 1900×1000 | 29.0 磅 | **8%** |

一张铺满桌面的卡片上放四个字，字只占宽度的 8%，而且没有任何办法调大。

### 修法

变成每张卡片自己的设置 `CardState.AutoFitMaxFontSize`：

```csharp
float start = Math.Min(_card.AutoFitMaxFontSize,
    Math.Max(AutoFitGuessFloor, Width / AutoFitGuessCharacters)) + _card.FontAdjustment;
```

- 默认 `DefaultAutoFitMaxFontSize = 29f` —— **升级不改变任何现有卡片的样子**
- 范围 `[7, 96]`，`Clamp()` 里夹住，手改配置文件也推不出去
- 菜单：文字设置 → 自动字号上限 ▸ 29 / 36 / 48 / 64 / 96 磅
- 顺带把 `20.0f` 和 `17.0f` 命名成 `AutoFitGuessFloor` / `AutoFitGuessCharacters` —— 它们只负责「起点大概多大」，不再是藏在表达式里的魔数

**为什么是「上限」而不是「设定值」**：它只在卡片本来能放更大字的时候起作用。小卡片上把上限放到 96 也不会溢出，仍然会往下缩到装得下。

**自动适应关掉时它置灰**。那时候没有自动字号，上限没有意义——留一个点了不动的条目，正是这个项目一直在修的那类问题。

## 二、字号…：45 次点击变成一次

「大一点」是 2 磅一步，从 7 到 96 要 45 次。新增「文字设置 → 字号…」，走已有的 `TextInputForm`：

```csharp
private void AskFontSize()
{
    string entered = TextInputForm.Prompt(this, _app, T("字号", "Font size"),
        T("输入字号（7 到 96 磅之间）。", "Type a size between 7 and 96 points."),
        CurrentFontSize().ToString("0.#", CultureInfo.InvariantCulture));
    if (entered == null) return;
    float size;
    if (!float.TryParse(...) || size < CardState.MinManualFontSize ||
        size > CardState.MaxManualFontSize)
    { MessageBox.Show(...); return; }
    SetManualFontSize(size);
}
```

`TextInputForm` 只把字符串原样交回来，**范围校验必须自己做**——否则输入 1000 会被当成合法值。

模态对话框会先关掉菜单，所以之后 `SetManualFontSize` 里改卡片尺寸是安全的（和「固定显示某一句」同一条路径）。

## 三、加粗 / 斜体：一键切换

`FontStyleValue` 是个位标志，粗体和斜体各自一位。菜单里两个勾选项直接切：

```csharp
private void SetFontStyle(FontStyle style, bool on)
{
    int value = _card.FontStyleValue;
    _card.FontStyleValue = on ? (value | (int)style) : (value & ~(int)style);
    _quoteFontSize = -1.0f;
    _app.Save();
    FitQuoteFont();
    GrowCardToText();
    BackOffToFittingSize();
}
```

- `value & ~(int)style` —— 关一个不能把另一个也清掉
- **改字形会改变字宽**，所以必须重新适应并让卡片能长大。不然就是「换了粗体，字被裁了」
- 勾选状态每次打开菜单都从 `_card.FontStyleValue` 读回来，因为字体对话框也能改它

## 四、一件没做的：文字不透明度

原本把它列在第一档，动手前发现不行：`TextRenderer.DrawText` 走的是 GDI，**会忽略颜色的 alpha 通道**。设成半透明也照样画成不透明。

要做只能走离屏合成：把文字画进一张位图，再按 alpha 贴回来。而 GDI 画进 32 位位图时不会写 alpha，边缘会跟黑色混出毛边——常见解法是把位图底色填成卡片背景色再整体半透明贴回，但那样**背景图片上会露出一块纯色补丁**。

所以它需要和「逐行排版」一起做（那时本来就要接管绘制），不是第一档。这一档只交了上面三项。
